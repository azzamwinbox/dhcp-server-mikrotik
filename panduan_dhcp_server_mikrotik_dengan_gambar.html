Konfigurasi DHCP Server pada MikroTik

Panduan singkat dan langkah demi langkah untuk membagikan alamat IP secara otomatis ke perangkat yang terhubung ke jaringan LAN.

Apa itu DHCP?

DHCP (Dynamic Host Configuration Protocol) adalah layanan yang memberikan konfigurasi jaringan secara otomatis kepada klien.

Fungsi utama

Membagikan IP address, subnet mask, gateway, dan DNS tanpa mengatur setiap perangkat satu per satu.

Manfaat

Pengelolaan jaringan lebih cepat, praktis, dan mengurangi risiko alamat IP bentrok.

Contoh topologi dan alamat IP

Contoh konfigurasi: router MikroTik melayani jaringan LAN melalui ether3. Sesuaikan nama interface dan alamat IP dengan jaringan milikmu.
KomponenContoh
Interface LANether3
IP MikroTik (gateway)192.168.100.1/24
Network192.168.100.0/24
IP untuk klien192.168.100.10–192.168.100.254
DNS1.1.1.1 dan 8.8.8.8

Langkah konfigurasi melalui Winbox

1

Hubungkan komputer ke MikroTik

Buka aplikasi Winbox, lalu masuk ke router menggunakan akun yang benar. Pastikan komputer terhubung ke port LAN.

2

Atur IP address pada interface LAN

Buka IP → Addresses → +. Isi address 192.168.100.1/24, pilih interface ether3, lalu klik Apply dan OK.

3

Buka menu DHCP Server

Pilih IP → DHCP Server, lalu klik tombol DHCP Setup.

4

Pilih interface LAN

Pilih ether3 sebagai interface DHCP Server, kemudian klik Next.

5

Ikuti wizard DHCP Setup

Pastikan nilai yang ditampilkan sesuai jaringan. Contoh: DHCP Address Space 192.168.100.0/24, Gateway 192.168.100.1, dan Address Pool 192.168.100.10-192.168.100.254. Lanjutkan dengan Next.

6

Tentukan DNS dan lease time

Isi DNS Server 1.1.1.1 dan 8.8.8.8. Lease Time dapat menggunakan 00:10:00 sebagai contoh, atau sesuaikan kebutuhan. Klik Next sampai wizard selesai.

7

Uji koneksi klien

Atur pengaturan IPv4 komputer/HP ke otomatis (DHCP), lalu sambungkan ulang jaringan. Perangkat seharusnya memperoleh IP dari rentang yang sudah dibuat.

Panduan konfigurasi bergambar

Berikut contoh tampilan Winbox sesuai urutan proses DHCP Setup. Perhatikan interface dan alamat IP pada router masing-masing karena contoh gambar dapat berbeda dari konfigurasi jaringanmu.

Alternatif konfigurasi melalui Terminal

Jalankan perintah berikut satu per satu pada Terminal MikroTik. Contoh ini mengasumsikan IP LAN 192.168.100.1/24 belum dipasang dan belum ada DHCP Server dengan konfigurasi serupa.

/ip address add address=192.168.100.1/24 interface=ether3
/ip pool add name=dhcp_pool ranges=192.168.100.10-192.168.100.254
/ip dhcp-server add name=dhcp_lan interface=ether3 address-pool=dhcp_pool disabled=no
/ip dhcp-server network add address=192.168.100.0/24 gateway=192.168.100.1 dns-server=1.1.1.1,8.8.8.8
Catatan penting: Jangan menambahkan IP address atau DHCP Server dua kali jika konfigurasi tersebut sudah ada. Pastikan pool tidak mencakup alamat yang dipakai router atau perangkat dengan IP statis. DHCP hanya membagikan konfigurasi IP; akses internet juga memerlukan konfigurasi WAN, routing, DNS, dan NAT yang benar.

Cara mengecek hasil konfigurasi

Di MikroTik

Buka IP → DHCP Server → Leases. Periksa apakah perangkat klien muncul dan mendapat alamat IP.

Di Windows

Buka Command Prompt dan jalankan ipconfig /all. Periksa IPv4 Address, Default Gateway, dan DHCP Enabled.

Jika belum berhasil

Pastikan kabel dan interface benar, DHCP Server aktif, pool tersedia, serta IP klien diatur otomatis.

Checklist praktik

0 dari 5 langkah selesai.

Kesimpulan

DHCP Server pada MikroTik memudahkan administrator membagikan alamat IP dan informasi jaringan secara otomatis kepada klien. Dengan menentukan interface LAN, gateway, rentang IP, serta DNS yang benar, perangkat dapat terhubung ke jaringan tanpa konfigurasi IP manual.
